# InfludbModifyTool

InfluxDB 超量程数据平滑处理工具（MFC 对话框程序，VS2010 工程 `TestInfluxDB_2.vcxproj`）。

## 使用方法

1. 填写 InfluxDB 地址（默认 `http://localhost:8086`）、数据库（默认 `mydb1`）、表名（默认 `TagValue`）。
2. 输入标签名（`TagName` 的值）、量程下限、量程上限。
3. 选择开始/结束时间，范围最长 6 个月。
4. 点击“开始处理”。程序按 6 小时一批读取数据，修正超出量程的值，并按原时间戳写回原标签（覆盖 `value` 字段，`Quality` 等其它字段不变）。

可选项：

- **仅预览**：只计算并在趋势图中显示处理效果，不写数据库。建议先预览确认效果。
- **写入前备份原始值到表**（默认不勾选，表名默认 `TagValue_Backup`）：被修改点的原始值先写入备份表，需要时可据此恢复。
- **按 UTC 解释输入时间**：勾选时与原程序一致，把输入的时间直接当作 UTC（查询串直接拼 `Z`）；不勾选则按本机时区换算。
- **过渡带(%)**：量程内侧用于平滑过渡的区域宽度，默认 5%。

## 平滑算法（DataSmoother.cpp）

温度、压力是缓慢变化的量，简单截断到上下限会得到一条被削平的直线。本工具的做法：

1. 在量程内侧留出过渡带，得到上拐点 `Ku = H - band`、下拐点 `Kl = L + band`。
2. 连续越过拐点的数据组成一个越界段；段内没有真正超量程的点时不做任何修改。
3. 对需要修正的段先做 5 点中值滤波去除孤立尖峰，再以拐点为基准按比例压缩：
   `新值 = Ku + (值 - Ku) × k`，`k = 0.85 × band / (段内峰值 - Ku)`。
   曲线起伏形状按比例保留、首尾与正常数据连续衔接，峰值落在量程内，不会被削平。
4. 量程内的数据保持原值，只写回被修改的点。
